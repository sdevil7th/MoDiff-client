# Qualified-example preview scope

The November 2026 release candidate selects 81 registered examples from the
original 89-case campaign. The executable selection is
`config/release-showcase-scope.v1.json`; it binds the exact immutable Dataset
revision and each accepted recipe. Run `npm run release:showcases:verify` to
verify that selection. This check does not replace the full release gate.

Marigold Depth LCM — Synthetic Ramp, SmolLM2 — Rain Gauge Answer, and Spandrel
Real-ESRGAN 2× — Synthetic Gradient are registered in the Gallery as supplements.
They count toward the workflow release report and sit outside the original
89-case selection.

Shap-E — Traffic Cone Turntable is also a supplement. Its approved 256 × 256
rendered turntable is an exact technical preview. It establishes the text-to-3D
workflow's rendered output and leaves mesh quality unmeasured.

Five originals remain deferred to AMD cloud: Amber Glass Replacement, The Winter
Delivery, Subway Musician, Final Mise en Place and Morning Light Teapot. Chinese
New Year Ensemble, Ghibli Story Illustration and Cosmos 3 Publisher Caption
remain excluded for rights/access reasons. Their rejected or unapproved outputs
must not become release showcases. The two-hour local campaign budget is an
operator scheduling choice; MoDiff imposes no corresponding user runtime limit.

The preview's evidence claims cover the selected accepted examples and their
recorded configurations. They do not qualify every canonical developer workflow,
declared memory/quantization variant or physical platform. CPU/NVIDIA qualification
remains limited to the existing measured baselines; AMD observations are
conditional and Apple MPS still needs physical qualification. Approved historical
media and current native recipe evidence remain distinct proof levels.

Before distributing the paired candidate, run the full client check and browser
checks, asset release gate, backend gate, integrated HTTP/package checks and the
current contract/resource report verifiers. Retain the full Gallery and global
qualification gate results, including exclusions and other missing execution
evidence. A failed global gate means the complete catalogue cannot be described
as a fully qualified stable release. A passing selected-example check supports a
clearly labelled preview with the documented limits.

Redux Courier now uses its accepted prompt, seed 8414, guidance 3.5 and 80/20
reference weights inside the generic Encode Inputs stage. Moonflower uses the
accepted nine-scene, 45-second Custom recipe and ten ordered image slots from
nine byte-pinned source files. Its lyric overlay is disabled by default. Original
media is retained; registration and input recovery require no model rerender.

Standalone deterministic utility evidence is separate from the 81-example scope.
The three input-free data utilities can qualify exact private text/JSON results
through the normal queue and canonical recorder, without a fictitious model
revision or public Gallery approval. The recorder checks their delivered and
persisted previews and exported bytes against an independent expected result.
This grants no model-memory, hardware, full consumed-field or browser-interaction
claim. File-backed media utilities and model-backed workflows retain their own
evidence requirements; see the canonical recorder in `CONTRIBUTING.md`.

The four DreamLite workflows qualify for noncommercial research with their
previews withheld. The checker repeats the saved evidence validation and binds
the exact accepted graph and output to the existing restricted artifact review.
The release report lists them separately under `previewFreeResearchWorkflows`.
Their proof does not extend to Gallery publication or Auto resource admission.
